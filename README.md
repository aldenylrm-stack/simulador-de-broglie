# Simulador de de Broglie — Aula 3

Site estático para uso na UEPS *O elétron é uma bolinha?*

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub, por exemplo `simulador-de-broglie`.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Vá em **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main`, a pasta `/(root)` e clique em **Save**.
6. Quando o GitHub concluir a publicação, o site deverá estar em:
   `https://SEU-USUARIO.github.io/simulador-de-broglie/`

A foto histórica depende de acesso ao Wikimedia Commons. Confira sua exibição nos computadores da escola antes de aplicar a atividade.
